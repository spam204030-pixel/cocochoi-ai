## 2026-11-24 — 작업 0-8 작업 대기열 + 단계 상태

- 작업 대기열(jobs) + 작업자(worker): `uv run factory` 하나로 화면과 함께 켜짐 (설계서의 "별도 워커 프로세스"를 같은 프로그램 안의 백그라운드 작업자로 단순화. 작업 상태는 DB에 있어 재시작 복구는 동일)

- 단계 처리기는 모두 "시험 실행(가짜 작업)" — AI 비용 0원, 결과에 fake 표시. Phase 1부터 단계별로 실제 기능으로 교체
- 콘텐츠 상세 화면: 진행 표시줄(상태 5종), 시작·일시정지·재개·취소·단계별 다시 실행 버튼, 진행 중 2초마다 자동 새로고침. 8단계가 끝나면 "검수 대기"(대표 최종 확인)
- API: `/api/projects/{id}/pipeline`, `/start`, `/pause`, `/resume`, `/cancel`, `/steps/{단계}/rerun`
- DB: 동시 읽기·쓰기를 위해 SQLite WAL 모드 사용
- 선택 설정: `FAKE_STEP_SECONDS`(시험 실행 단계당 시간, 기본 1.5초), `FAKE_FAIL_STEP`(시험용으로 실패시킬 단계)
