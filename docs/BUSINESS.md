# COCOCHOI 사업 방향 (2026년 11월 확정)

## 정의
쿠팡파트너스와 네이버 애드포스트를 중심으로 콘텐츠 수익을 만드는 **AI 미디어 커머스 시스템**.
자체 쇼핑몰 판매가 아니라, 패션 MD의 안목으로 상품과 정보를 골라주는 콘텐츠로 수익을 낸다.

## 운영 원칙
**조사와 초안은 AI가, 얼굴·안목·검수·발행은 대표가 한다.**

대표의 하루: 추천 주제 확인 → 1개 선택 → 촬영/검수 → 직접 발행 (1~2시간)

## 콘텐츠 흐름
트렌드 발견 → 주제·상품 점수화 → TOP 5 추천 → 대표 선택 → 블로그·쇼츠·캡션 생성 → 발행 → 성과 기록 → 다음 추천에 반영

## 채널별 목표
| 콘텐츠 | 목표 지표 |
|---|---|
| 쇼핑 쇼츠 (유튜브·릴스) | 조회수, 구독자 증가, 링크 클릭 |
| 네이버 블로그 정보 글 | 검색 유입, 체류시간, 애드포스트 수익 |
| 네이버 블로그 상품 글 | 쿠팡 링크 클릭, 구매 |
| 인스타 카드뉴스 | 저장, 공유, 팔로워 |

## 링크 경로 (현재 기준)
- 유튜브 쇼츠는 설명란·댓글 링크를 눌러서 이동할 수 없다 → 쇼츠는 구독자 성장용
- 인스타: 프로필 링크, 댓글 키워드 → DM으로 링크 전달
- 네이버 블로그: 쿠팡 링크 + 애드포스트
- 성장 목표: 유튜브 쇼핑 제휴 프로그램 자격 확보 (쇼츠에 쿠팡·퀸잇 상품 태그 가능)

## 개발 순서
1. `/트렌드` — 오늘/이번 주 콘텐츠 주제 TOP 5 추천 (웹 검색 기반, API 없음) ← 지금
2. `/만들기` — 선택한 주제로 블로그·쇼츠·캡션 생성 ← 지금
3. 네이버 API HUB(검색어트렌드·쇼핑인사이트) + YouTube Data API 연결로 정확도 향상
4. 성과 기록 → 주간 분석 → 다음 추천 개선
5. 샤오홍수·인스타 레퍼런스 분석 (대표가 링크·캡처 입력 → AI 분석)
